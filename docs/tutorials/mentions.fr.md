# Mentions et tags

Une Mention relie ce que vous écrivez à un Sujet, une Source ou tout autre document. Écrivez-la dans la phrase quand le nom y a sa place, ou en tag quand il compte mais alourdirait le texte : c'est le même lien.

1. Ouvrez une de vos Notes. Un nom écrit `[[Paul]]` s'affiche comme un lien dans sa phrase ; les pastilles sous le titre sont les tags de la Note. Cliquez sur l'un ou l'autre : la page qu'il nomme s'ouvre.
2. Sur cette page, **Liens entrants** liste votre Note une seule fois, quel que soit le nombre de mentions. Un tag est le même lien qu'un lien dans la phrase ; sa ligne est seulement marquée `#`.
3. Créez une Note d'essai avec [Nouvelle Note](command:create.note). Écrivez une phrase et, là où un nom a sa place, lancez [Insérer un lien](command:editor.link) : `[[` s'insère et vos documents s'affichent au fil de la frappe. Choisissez-en un et le nom devient un lien.
4. Essayez une fois : sous le titre, cliquez sur **Ajouter un tag** et nommez un Sujet absent de votre phrase. Ouvrez la page taguée puis la page liée : votre Note figure dans leurs **Liens entrants**. Gardez la Note, ou supprimez-la avec le bouton de suppression de son en-tête.

## À savoir

- Un tag peut aussi aller dans le texte : [Insérer un tag](command:editor.tag) tape `#` et liste vos tags et vos pages.
- Tout tag nomme un document. S'il n'existe pas encore de page à ce nom, cliquer sur le tag propose **Créer la page**.
- Un tag de plusieurs mots s'écrit avec des tirets : `#second-voyage`.
