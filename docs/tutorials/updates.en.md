# Updates

Synesis on a computer looks for a new version by itself and tells you when one is ready; you choose when to install it. Phones get theirs from their app store.

1. [Go to Settings](command:nav.settings) and find **Updates**. It shows the version you have, and the switch that lets Synesis look for a new one each time it starts.
2. When a new version exists, a strip at the top of the window says **Synesis X is available**. **Install & restart** downloads it, checks that it really comes from Synesis, installs it and opens the new version; **Later** hides the strip until the next start.
3. Try it once: run [Check for updates](command:app.check_updates). Settings says whether you are up to date, or offers the new version.

## Good to know

- Every update is signed, and one whose signature does not match is refused.
- An update never touches your Vault: it stays your folder of markdown files.
- The **About** card shows the licence and links to the source code.
