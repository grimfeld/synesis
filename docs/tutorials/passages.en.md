# Passages

Type a Scripture reference the way you usually write it and the app recognises it as a Passage: it links to every Verse it covers, while your text stays exactly as you typed it.

![One Passage linking to each Verse it covers](image:passages)

1. Open one of your Notes, or create one with [New Note](command:create.note). Each reference that has a chapter number, such as `Ro 8:28` or `Acts 20`, is underlined as a Passage.
2. Click a Passage. A card names it in full and lists the other documents that mention those Verses; **Open page** takes you to its Verse or Chapter page, which gathers every one of them.
3. To reach a page with no reference to click, run [Open a Passage…](command:nav.passage), type `Ro 8` or `John 3:16` and press **Open**.
4. Try it once: create a Note with [New Note](command:create.note) and type a reference in English or in French, such as `Ro 12:2` or `Jean 3,16`. It is underlined as you type. Click it, then **Open page**: your Note is listed on that Verse's page. Delete the Note from its header if it was only a test.

## Good to know

- A book name alone is not a Passage: `Acts` needs a chapter. Link a whole Book as `[[Acts]]`.
- `v. 17` after a Passage in the same paragraph counts too, with a different underline.
- A range covers every Verse in it, across chapters too: `Ge 1:1-2:3`.
- The underline is only a decoration. The file keeps what you typed, so Obsidian shows it unchanged.
- [Go to Coverage](command:nav.coverage) shades every chapter by how much you have written on it.
