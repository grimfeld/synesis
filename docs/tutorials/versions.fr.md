# Versions

Une version est un moment nommé d'une composition, comme « Telle que donnée, 2026-09-20 », que vous pouvez relire, comparer au texte actuel ou restaurer. Enregistrez-en une avant de retravailler un discours, ou juste après l'avoir donné.

1. Ouvrez une composition que vous écrivez, ou créez-en une avec [Nouvelle Composition](command:create.composition). Le panneau latéral, à côté du texte, a une section **Versions** ; s'il est masqué, affichez-le avec son bouton en haut à droite.
2. Tapez un nom dans la zone, par exemple « Avant ce tutoriel », et appuyez sur **Enregistrer une version**. La version garde ensemble le texte et le tableau ; sans nom, elle prend la date et l'heure.
3. Ajoutez une ligne à la fin du texte, puis cliquez sur la version dans la liste. La comparaison marque d'un − ce que la version a et que le texte n'a plus, et d'un + ce qui a été ajouté depuis : votre nouvelle ligne.
4. Appuyez sur **Restaurer ce texte**. Le texte de la version revient comme une nouvelle modification : votre ligne disparaît, mais rien n'est effacé. **Parcourir l’historique** garde le moment où elle y était, et la version reste dans la liste. Sa corbeille la supprime si vous n'en voulez plus.
5. Essayez une fois : sur le prochain discours que vous donnerez, enregistrez une version nommée d'après l'occasion, par exemple « Telle que donnée, 2026-10-04 ». Après votre prochaine reprise, ouvrez-la pour voir ce qui a changé.

## À savoir

- Les versions vivent dans la composition, pas dans des fichiers à part : elles la suivent sur vos autres appareils.
- **Parcourir l’historique** liste chaque enregistrement, nommé ou non ; chaque moment s'y ouvre comme une version.
- Si le tableau a changé aussi, la comparaison a un onglet **Tableau** qui liste les cartes ajoutées, retirées et déplacées.
