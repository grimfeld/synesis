# Versions

A Version is a named moment of a Composition, such as "As delivered, 2026-09-20", that you can read again, compare with the current text or restore. Save one before you rework a talk, or right after you give it.

1. Open a Composition you are writing, or create one with [New Composition](command:create.composition). The side panel beside the text has a **Versions** section; if the panel is hidden, show it with its button at the top right.
2. Type a name in the box, such as "Before this Tutorial", and press **Save version**. The Version keeps the text and the Board together; left blank, the name is the date and time.
3. Add a line at the end of the text, then click the Version in the list. The comparison marks with − what the Version has and the text no longer does, and with + what was added since: your new line.
4. Press **Restore this text**. The Version's text comes back as a new edit, so your added line goes, but nothing is rewound: **Browse history** still holds the moment with the line in it, and the Version stays in the list. Its bin deletes it if you no longer want it.
5. Try it once: on the talk you will give next, save a Version named for the occasion, such as "As delivered, 2026-10-04". After your next rework, open it to see what changed.

## Good to know

- Versions live inside the Composition, not as separate files, so they travel with it to your other Devices.
- **Browse history** lists every save, named or not; any moment in it opens the same way as a Version.
- When the Board changed too, the comparison has a **Board** tab listing the cards added, removed and moved.
