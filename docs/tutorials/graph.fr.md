# Le graphe

Le graphe dessine tout votre coffre d'un coup : chaque document est un point, coloré selon son type, et chaque mention est un trait entre deux points. Il montre quels documents se regroupent autour d'un même passage ou sujet, et lesquels ne sont encore liés à rien.

1. Parcourez le graphe. Chaque passage que vous mentionnez devient un point des Écritures : les notes sur un même chapitre s'y rejoignent. Pointez un point pour éclairer ce qui y est relié ; faites glisser le fond pour vous déplacer, la molette ou deux doigts pour zoomer, et **Tout afficher** pour tout recadrer.
2. Dans l'en-tête, passez **Niveau des Écritures** de Chapitre à Livre : chaque chapitre se replie dans son livre, et les nombres en bout d'en-tête (points · traits) baissent. Verset les divise dans l'autre sens. Remettez ensuite Chapitre.
3. Resserrez. Tapez dans **Rechercher** pour estomper tout point dont le nom ne correspond pas. Les boutons à côté activent ou masquent chaque type : désactivez **Écritures** pour ne voir que les liens entre vos documents.
4. Essayez une fois : tapez le titre d'une de vos notes dans **Rechercher**, puis cliquez sur son point. La note s'ouvre ; [Aller à Graphe](command:nav.graph) vous ramène ici.

   Pas encore de note ? Écrivez-en une avec [Nouvelle Note](command:create.note) en y citant un passage, par exemple Romains 8. Supprimez-la ensuite avec le bouton de suppression de son en-tête.

## À savoir

- Une étiquette est aussi une mention : un document étiqueté est relié au document que l'étiquette nomme.
- Un point cerclé est un chapitre ou un verset qui n'a pas encore sa propre page ; un clic l'ouvre quand même.
- Le niveau des Écritures est mémorisé ; la recherche et les boutons de type repartent de zéro à chaque ouverture du graphe.
