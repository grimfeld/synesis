# Dossiers

Les dossiers rangent vos notes et vos compositions dans la barre latérale. Un dossier est un dossier ordinaire dans `Notes` ou `Compositions` de votre coffre : celui que vous créez dans le Finder, l'Explorateur ou Obsidian apparaît donc ici aussi. Les dossiers ne font que ranger : le sujet d'un document reste dit par ses étiquettes et ses mentions.

1. Ouvrez la barre latérale et regardez les groupes **Notes** et **Compositions**. Les dossiers viennent d'abord, puis les documents, chacun dans l'ordre naturel (« Semaine 2 » avant « Semaine 10 »). Le nombre sur la ligne d'un dossier compte tous les documents qu'il contient, y compris dans ses sous-dossiers.
2. Cliquez sur la ligne d'un dossier pour le déplier, et encore pour le replier. Les dossiers sont repliés au départ, et l'app retient sur cet appareil ceux que vous avez ouverts. Ouvrez une note rangée dans un dossier avec [Rechercher](command:nav.search) : les dossiers qui la contiennent se déplient d'eux-mêmes.
3. Essayez une fois : à côté de **Notes**, ouvrez le menu **…** et choisissez **Nouveau dossier**. Tapez un nom, par exemple « Sermons 2026 », et appuyez sur **Créer** : le dossier apparaît avec 0 à côté, et dans votre coffre c'est le dossier `Notes/Sermons 2026`. Rangez-y maintenant une note : ouvrez le **…** à côté d'une note et choisissez [Déplacer vers un dossier…](command:doc.move_to_folder), puis « Sermons 2026 ». Sur un ordinateur, vous pouvez aussi faire glisser la note sur le dossier. Le dossier compte maintenant 1.

## Bon à savoir

- Un dossier créé, renommé ou supprimé hors de l'app apparaît modifié dans la barre latérale en quelques secondes.
- Une note ou une composition rangée hors de son propre dossier est listée sous son vrai chemin depuis la racine du coffre, précédé d'un `/` : `/Étude` pour un dossier à vous, `/` pour la racine du coffre elle-même.
- Seules les notes et les compositions ont des dossiers. Les sources sont sur les étagères de la bibliothèque ; lieux, personnages, concepts et événements restent dans leurs propres groupes.
- Survolez un dossier pour voir son chemin complet dans le coffre. Sur un ordinateur, un clic droit sur un dossier ouvre son menu.
- Le menu **…** d'un dossier crée aussi un dossier à l'intérieur. Un nom ne peut pas être vide, commencer par un point, contenir `/ \ : * ? " < > |`, ni reprendre un nom déjà présent à côté (quelles que soient les majuscules).
- Le **+** d'un dossier écrit une nouvelle note directement dedans. Une note garde son titre quand elle change de dossier ; un dossier qui contient déjà un fichier du même nom la refuse plutôt que d'ajouter un numéro. Le tableau d'une composition la suit.
- Le menu **…** d'un dossier le renomme aussi (ses documents restent dedans, leurs titres et tous les liens vers eux inchangés) et le déplace dans un autre dossier avec **Déplacer vers un dossier…** ; sur un ordinateur, vous pouvez faire glisser un dossier sur un autre, ou sur **Notes** pour le remettre en haut. Un dossier ne va jamais dans lui-même, et ne prend jamais un nom déjà présent à côté.
- Seul un dossier vide peut être supprimé : ranger ne supprime jamais un document. Les fichiers que votre ordinateur laisse de lui-même (`.DS_Store`, `Thumbs.db`) ne comptent pas.
- [Nouvelle note](command:create.note), la saisie rapide de l'accueil et la palette de commandes placent toujours une nouvelle note en haut de `Notes` ; seul le **+** d'un dossier la place dedans.
