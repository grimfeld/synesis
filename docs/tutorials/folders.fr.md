# Dossiers

Les dossiers rangent vos notes et vos compositions dans la barre latérale. Un dossier est un dossier ordinaire dans `Notes` ou `Compositions` de votre coffre : celui que vous créez dans le Finder, l'Explorateur ou Obsidian apparaît donc ici aussi. Les dossiers ne font que ranger : le sujet d'un document reste dit par ses étiquettes et ses mentions.

1. Ouvrez la barre latérale et regardez les groupes **Notes** et **Compositions**. Les dossiers viennent d'abord, puis les documents, chacun dans l'ordre naturel (« Semaine 2 » avant « Semaine 10 »). Le nombre sur la ligne d'un dossier compte tous les documents qu'il contient, y compris dans ses sous-dossiers.
2. Cliquez sur la ligne d'un dossier pour le déplier, et encore pour le replier. Les dossiers sont repliés au départ, et l'app retient sur cet appareil ceux que vous avez ouverts.
3. Essayez une fois : [cherchez](command:nav.search) une note rangée dans un dossier et ouvrez-la. Les dossiers qui la contiennent se déplient d'eux-mêmes, pour que vous voyiez où elle se trouve. Repliez maintenant le dossier qui la contient, puis dépliez-le à nouveau. (Pas encore de dossier ? Créez-en un dans `Notes` avec le Finder, l'Explorateur ou Obsidian, mettez-y une note : il apparaît ici en quelques secondes.)

## Bon à savoir

- Un dossier créé, renommé ou supprimé hors de l'app apparaît modifié dans la barre latérale en quelques secondes.
- Une note ou une composition rangée hors de son propre dossier est listée sous son vrai chemin depuis la racine du coffre, précédé d'un `/` : `/Étude` pour un dossier à vous, `/` pour la racine du coffre elle-même.
- Seules les notes et les compositions ont des dossiers. Les sources sont sur les étagères de la bibliothèque ; lieux, personnages, concepts et événements restent dans leurs propres groupes.
- Survolez un dossier pour voir son chemin complet dans le coffre.
