# The Command Palette

One box finds any document in your Vault and runs any Command, so you never need to hunt through menus. It searches titles first, then what documents say.

1. Open [Search](command:nav.search) and type a few letters of a title you remember. Notes, Sources and Subjects all come up together; press Enter to open the highlighted one.
2. Open it again and type `>` before anything else. The box now lists Commands instead of documents, each with its keyboard shortcut if it has one. [Command palette](command:nav.commands) opens it that way directly.
3. Try it once: open the palette, type `>timeline` and press Enter on **Go to Timeline**. The Timeline opens, and this Tutorial stays beside it.

## Good to know

- Every Tutorial is a Command too: type `>tutorial` to see them all.
- A shortcut shown in the palette works anywhere in the app, except while you are typing in a box that uses the same keys.
