# Les Sources et la Bibliothèque

Une Source est l'œuvre de quelqu'un d'autre que vous étudiez : un livre, un périodique, un article, une vidéo, un discours. La Bibliothèque range toutes vos Sources sur des étagères par genre : vous voyez d'un coup d'œil ce que vous avez, et vous ouvrez ce que vous voulez.

![Des Sources sur des étagères par genre, chacune avec sa couverture](image:library)

1. Ouvrez la [Bibliothèque](command:nav.library). Chaque étagère regroupe les Sources d'un même genre, et chaque carte montre la couverture de la Source : l'image que vous lui avez donnée, ou une couverture dessinée d'après son titre, son genre et sa date.
2. Cliquez sur une carte pour ouvrir la page de la Source (si la Bibliothèque est vide, l'étape suivante en ajoute une). Le chapitre d'un livre ou le numéro d'un périodique est aussi une Source, mais il se range dans son parent : il figure sous **Contient** sur la page du parent et n'a jamais d'étagère à lui.
3. Essayez une fois : ajoutez ce que vous lisez avec [Nouvelle Source](command:create.source). Donnez un **Titre**, choisissez le **Genre**, une **Couverture** si vous voulez, laissez **Fait partie de** vide et appuyez sur **Créer**. Sur sa page, tapez le titre d'un chapitre dans la zone sous **Contient**, puis Entrée. De retour dans la [Bibliothèque](command:nav.library), votre Source est sur son étagère et sa carte compte une partie. Pour les retirer, utilisez le bouton **Supprimer** dans l'en-tête de chaque page.

## À savoir

- Une Source d'un genre que l'application ne connaît pas, ou un chapitre dont le parent manque, attend sur la rangée **À ranger** jusqu'à ce que vous corrigiez son **Genre** ou **Fait partie de**.
- La page d'un parent rassemble tout ce qui est cité depuis les Sources qu'il contient.
