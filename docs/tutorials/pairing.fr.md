# Appairage

L'appairage fait que deux de vos appareils se font confiance pour un coffre : ils se synchronisent directement, sans compte ni service de synchro. Une fois par appareil : celui-ci montre un code, l'autre l'utilise, et vous l'autorisez ici.

1. [Aller à Réglages](command:nav.settings). Sous **Synchronisation** → **Appairer vos appareils**, appuyez sur **Afficher le code d'appairage**. Un QR code et une ligne de texte apparaissent : le code de ce coffre. Il reste valable jusqu'à **Révoquer et créer un nouveau code**, et aucun appareil n'entre sans votre accord.
2. Regardez la liste sous le code : chaque appareil qui a ce coffre, celui-ci marqué *(cet appareil)*. Un point vert signifie en ligne. La corbeille à côté d'un autre appareil le retire du coffre.
3. Essayez une fois : sur votre téléphone ou un autre ordinateur, installez Synesis et ouvrez-le. Appuyez sur **Commencer**, puis **Associer un autre appareil** ; scannez le QR code avec **Scanner**, ou collez le texte, et appuyez sur **Rejoindre depuis un autre appareil**.

   De retour sur cet appareil, **Autorisez** la demande qui s'affiche. L'autre appareil reçoit le coffre et apparaît dans la liste. Désormais les deux se synchronisent directement dès qu'ils sont en ligne : écrivez une ligne sur l'un, elle arrive sur l'autre.

## À savoir

- Quiconque a le code peut demander à entrer : gardez-le pour vous. Révoquer en crée un nouveau et l'ancien ne marche plus.
- **Continuer la synchronisation en arrière-plan** permet à cet appareil de se synchroniser même fenêtre fermée.
- Sur un appareil où un coffre est déjà ouvert, appuyez d'abord sur **Fermer ce coffre** dans les réglages. L'écran d'accueil liste alors **Vos coffres** ; **Nouveau coffre** mène à **Associer un autre appareil**.
