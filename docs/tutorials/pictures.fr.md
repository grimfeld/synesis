# Images

Une carte, une page scannée ou la photo d'un site peuvent prendre place dans n'importe quelle Note, Composition, Extrait ou « À propos ». Déposez-la, collez-la ou choisissez-la : l'image est copiée dans le dossier `Attachments` de votre coffre et s'affiche là où vous l'avez mise.

1. Ouvrez une de vos Notes avec [Rechercher](command:nav.search). Faites glisser un fichier image de votre ordinateur sur le texte. Elle apparaît sur sa propre ligne, là où vous l'avez déposée.
2. Cliquez sur l'image. Sa ligne montre ce qui est enregistré, `![[Attachments/…]]`, nommé d'après la Note. Placez le curseur sur une autre ligne : l'image revient.
3. Essayez une fois : créez une Note avec [Nouvelle Note](command:create.note) (son bouton **Supprimer** dans l'en-tête l'enlève ensuite). Lancez [Insérer une image](command:editor.picture) et choisissez une image : elle apparaît au curseur.

## À savoir

- Coller une capture d'écran fonctionne aussi. Seules les images jpg, png, gif et webp peuvent aller dans le texte ; les autres fichiers sont refusés.
- Le « À propos » d'une page accepte les images de la même façon, même avant d'y avoir rien écrit : déposez-en une sur son cadre vide.
- Les images sont enregistrées en 1600 pixels au plus, pour que le coffre et la synchronisation restent légers. Un gif animé est gardé tel quel.
- Le mode source ne montre que le texte, `![[…]]` compris. Obsidian affiche les mêmes images.
- Supprimer la ligne retire l'image du texte, pas d'`Attachments` : annuler la fait toujours revenir.
- Un Appareil jumelé reçoit l'image avec le texte.
