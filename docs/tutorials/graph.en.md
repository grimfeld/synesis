# The Graph

The Graph draws your whole Vault at once: every document is a dot, coloured by its type, and every Mention is a line between two dots. Use it to see which documents gather around the same Passage or Subject, and which ones nothing links to yet.

1. Look over the Graph. Each Passage you mention becomes a Scripture dot, so Notes about the same Chapter meet there. Point at a dot to light up what it is joined to; drag the background to move around, scroll or pinch to zoom, and press **Fit all** to frame everything again.
2. In the header, change **Scripture level** from Chapter to Book: every Chapter dot folds into its Book, and the counts at the end of the header (dots · lines) drop. Verse splits them the other way. Set it back to Chapter afterwards.
3. Narrow it down. Type in **Search** to dim every dot whose name does not match. The buttons beside it switch each type on and off: turn off **Scripture** to see only how your own documents link to each other.
4. Try it once: type the title of one of your Notes in **Search**, then click its dot. The Note opens; [Go to Graph](command:nav.graph) brings you back.

   No Note yet? Write one with [New Note](command:create.note) and name a Passage in it, such as Romans 8. Remove it later with the delete button in its header.

## Good to know

- A Tag is a Mention too, so a tagged document is joined to the document the Tag names.
- A dot with a ring is a Chapter or Verse that has no page of its own yet; clicking it opens that page anyway.
- The Scripture level is remembered; search and the type buttons start afresh each time you open the Graph.
