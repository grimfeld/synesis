# Deux documents côte à côte

Lire un document en en écrivant un autre ne demande plus d’aller-retour : une fenêtre affiche jusqu’à deux volets côte à côte, et chacun avance et recule de son côté. Le panneau latéral, la palette de commandes et Retour suivent le dernier volet utilisé, marqué d’une fine ligne le long de son bord supérieur.

1. Ouvrez la note que vous écrivez avec [Rechercher](command:nav.search). Maintenez Cmd (Ctrl sous Windows et Linux) et cliquez sur un lien : ce qu’il nomme s’ouvre dans un second volet à droite, et la note reste à gauche. [Ouvrir dans l’autre volet](command:pane.open_other) fait de même pour toute la page où vous êtes.
2. Cliquez dans le volet de gauche. La fine ligne passe de son côté, et le panneau latéral décrit désormais son document. Ouvrez-y autre chose, puis appuyez sur [Retour](command:nav.back) : seul le volet de gauche revient en arrière, celui de droite garde ce qu’il affiche.
3. Faites glisser le séparateur entre les deux volets pour donner plus de place à l’un d’eux. Cliquez sur le séparateur : les flèches du clavier le déplacent aussi. Chaque volet garde au moins 320 pixels.
4. Lancez [Échanger les volets](command:pane.swap) pour mettre le document où vous écrivez de l’autre côté. Chacun garde son historique et sa largeur.
5. Essayez une fois : dans une de vos notes, cliquez sur un lien avec Cmd ou Ctrl pour lire ce qu’il nomme à côté de votre texte, puis lancez [Fermer le volet](command:pane.close) dans le volet dont vous n’avez plus besoin. L’autre reste.

## À savoir

- Deux volets demandent de la place pour les deux. Sur un téléphone, il n’y a jamais qu’un volet, et un clic avec Cmd ou Ctrl ouvre un lien comme un clic simple. Dans une fenêtre trop étroite pour les deux, seul le dernier volet utilisé s’affiche ; élargissez la fenêtre, ou fermez la barre latérale ou le panneau latéral, et l’autre revient.
- Le discours et le tableau d’une composition peuvent toujours se partager un volet, s’il a la place.
- Quand deux volets sont ouverts, ils reviennent tels quels la prochaine fois que vous ouvrez ce coffre sur cet appareil. Un seul volet s’ouvre sur l’Accueil, comme toujours.
- Tant que deux volets s’affichent, chacun a son propre **×** dans son en-tête, qui le ferme.
- Le même document peut être ouvert dans les deux volets. Ce que vous tapez dans l’un apparaît aussitôt dans l’autre, qui garde sa propre place dans le texte.
