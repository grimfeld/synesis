# Noms liables et mentions non liées

Un nom écrit sans lien passe vite inaperçu. Pendant que vous écrivez, l'application montre quels noms du document correspondent à un de vos Sujets ou à une de vos Sources, pour les lier sur place ; la page d'un Sujet montre la même chose depuis l'autre bout.

1. Ouvrez une de vos Notes. Dans le panneau latéral, **Noms liables** liste les Sujets et Sources qu'elle nomme sans les lier : une ligne par nom, avec un compte s'il revient plusieurs fois.
2. Cliquez sur un nom de cette liste. L'éditeur sélectionne l'endroit où il est écrit, pour le relire dans son contexte avant de décider. C'est l'icône de lien à côté qui en fait une Mention.
3. Ouvrez la page d'un de ces Sujets. Sous **Mentions non liées**, à côté de **Liens entrants**, figurent les documents qui écrivent son nom sans le lier, chacun avec la phrase où il apparaît.
4. Essayez une fois : créez une Note avec [Nouvelle Note](command:create.note) et écrivez une phrase qui nomme deux de vos Lieux ou Personnages (créez-en un avec [Nouveau Personnage](command:create.character) si vous n'en avez pas). Cliquez sur l'icône de lien du premier dans **Noms liables** : les mots restent tels quels, devenus un lien. Ouvrez ensuite la page du second et cliquez sur l'icône de lien de votre Note sous **Mentions non liées** : elle passe dans **Liens entrants**.

## À savoir

- Les Écritures n'y figurent jamais : un passage est déjà une Mention.
- Un alias compte : écrire « Saul » propose un lien vers Paul si Saul est un de ses alias.
- Lier une occurrence retire le nom de la liste ; les autres restent du texte simple.
- Sur une page, **Tout lier** lie la première mention de chaque document listé, après vous les avoir montrés. **Annuler** dans la notification remet les mots.
