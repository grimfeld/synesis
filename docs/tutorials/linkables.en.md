# Linkables & Unlinked mentions

A name you wrote without linking is easy to miss. While you write, the app shows which names in the document match one of your Subjects or Sources, so you can link them where they stand; a Subject's page shows the same thing from the other end.

1. Open one of your Notes. In the side panel, **Linkable names** lists the Subjects and Sources it names without linking: one row per name, with a count when it is written more than once.
2. Click a name in that list. The editor selects where it is written, so you can read it in context before deciding. The link icon beside it is what makes it a Mention.
3. Open the page of one of those Subjects. Under **Unlinked mentions**, next to **Backlinks**, are the documents that write its name without linking it, each with the sentence it appears in.
4. Try it once: create a Note with [New Note](command:create.note) and write a sentence naming two of your Places or Characters (make one with [New Character](command:create.character) if you have none). Click the link icon beside the first in **Linkable names**: the words stay as you wrote them, now a link. Then open the second one's page and click the link icon beside your Note under **Unlinked mentions**: it moves to **Backlinks**.

## Good to know

- Scripture is never listed: a Passage is already a Mention.
- An alias counts: writing "Saul" offers a link to Paul when Saul is one of Paul's aliases.
- Linking one occurrence takes the name off the list; the others stay plain prose.
- On a page, **Link all** links the first mention in each listed document, after showing you which ones. **Undo** in the notice puts the words back.
