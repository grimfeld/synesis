# Couverture

La couverture montre combien vous avez écrit sur chaque partie des Écritures : un carré par chapitre, coloré selon le nombre de vos documents qui le mentionnent. Elle révèle où votre étude est allée loin et quels livres vous n'avez pas encore abordés.

1. Lisez la grille : une ligne par livre, d'abord les Écritures hébraïques et araméennes, puis les Écritures grecques chrétiennes. Un carré gris est un chapitre que rien ne mentionne encore ; plus il est foncé, plus de documents le mentionnent. Le nombre dans l'en-tête compte les chapitres sur lesquels vous avez écrit, sur 1 189.
2. Pointez un carré pour voir son chapitre et combien de documents le mentionnent. Cliquez sur le nom d'un livre pour ouvrir sa page, où ses chapitres sont colorés de la même façon, puis revenez avec [Aller à Couverture](command:nav.coverage).
3. Essayez une fois : repérez le carré le plus foncé, le chapitre sur lequel vous avez le plus écrit, et cliquez dessus. Sa page s'ouvre : les versets y sont colorés de la même façon, et un verset ouvre les documents qui le mentionnent.

   Tous les carrés sont gris ? Écrivez une note avec [Nouvelle Note](command:create.note) qui cite un passage, par exemple Romains 8:28, puis revenez : son chapitre est coloré. Supprimez ensuite la note avec le bouton de suppression de son en-tête.

## À savoir

- Un document compte une fois par chapitre, quel que soit le nombre de ses mentions, et tous les types comptent : notes, extraits, compositions, sujets.
- Un passage qui couvre plusieurs chapitres les colore tous.
