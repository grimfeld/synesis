# Clippings

A Clipping keeps someone else's words exactly as they wrote them, together with the Source they come from and where in it (its Locator). Keep one whenever a sentence is worth quoting later; the Clippings view finds it again when you remember only what was said.

1. Open [Clippings](command:nav.clippings). Every Clipping is shown as its own words, newest first, with its Source and Locator underneath. Click a Tag or a Source above the list to narrow it, and **Clear filters** to see them all again.
2. Click a Clipping to open it. It has no title: its header is its Citation, the Source and Locator, which is also what names it wherever it is linked.
3. Open a Source you are reading from the [Library](command:nav.library), or create one with [New Source](command:create.source). The box at the top of its page keeps Clippings from that Source without leaving it.
4. Try it once: on that Source's page, run [Capture from this Source](command:doc.capture). With **Clipping** selected, paste or type the words you are keeping, put where they are in the Locator box (a paragraph, page or timestamp) and press **Create**. The Clipping appears on the page and at the top of [Clippings](command:nav.clippings). To remove it, open it and use the **Delete** button in its header.

## Good to know

- The same box writes a Note about the Source instead: select **Note** before you type.
- A Clipping is stored as a quotation in a markdown file named after its Citation, so it reads the same in Obsidian.
