# Pages et liens entrants

Chaque Source et chaque Sujet a sa page : un Livre, un Chapitre ou un Verset, un Lieu, un Personnage, un Concept, un Événement ou un Voyage. On la lit plus qu'on ne l'écrit : elle rassemble tout ce qui, dans votre coffre, pointe vers elle.

1. Ouvrez une de ces pages : cliquez sur un lien vers un Sujet dans une de vos notes, trouvez-la par son nom avec [Rechercher](command:nav.search), ou ouvrez un verset avec [Ouvrir un passage…](command:nav.passage). L'en-tête dit de quel genre de page il s'agit ; en dessous vient ce qui lui est propre, comme la carte d'un Lieu, les extraits d'une Source ou les dates d'un Personnage.
2. Descendez jusqu'à **Liens entrants** : chaque document qui mentionne cette page, une ligne par document, quel que soit le nombre de mentions. Sur la page d'un Sujet, ils sont groupés par Livre, dans l'ordre biblique. Une ligne qui la mentionne plusieurs fois l'indique ; sa flèche, **Afficher toutes les mentions**, les liste une à une.
3. Cliquez sur un lien entrant pour ouvrir ce document, puis revenez avec [Retour](command:nav.back).
4. Essayez une fois : ouvrez la page d'un Sujet ou d'une Source que vous étudiez et, sous **À propos** tout en bas, cliquez sur l'invite et écrivez une ligne avec vos mots : pourquoi il compte pour vous, ou par où commencer la lecture. Elle est enregistrée dans le fichier de la page, et les passages et liens y fonctionnent comme dans une note. Si l'À propos contient déjà du texte, ajoutez le vôtre à la suite.

## À savoir

- Une étiquette et un lien dans une phrase sont la même mention : les deux créent un lien entrant.
- **Mentions non liées**, à côté des liens entrants, liste les documents qui écrivent le nom de cette page sans la lier.
- Une page liste aussi ses tableaux : les compositions dont le tableau porte une carte vers elle.
